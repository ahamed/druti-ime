Druti @VERSION@ types Bengali phonetically in any app on your Mac.

## Install

1. Download **Druti-@VERSION@.dmg** below and open it.
2. Double-click **Druti**. It installs itself into your Input Methods folder and turns itself on.
3. If macOS says it can't verify Druti, open **System Settings → Privacy & Security**, scroll down,
   click **Open Anyway** next to Druti, and open Druti again. macOS asks once, because Druti is
   signed ad hoc and not notarized by Apple.
4. Choose Druti in the input menu in the menu bar, or press Control-Space (or 🌐) to switch to it.

Prefer a zip? Download **Druti-@VERSION@.app.zip** instead, unzip it and open **Druti** from
there. It's the same app as in the DMG and installs the same way.

Already have Druti? Opening the new DMG's Druti replaces it and keeps your settings.
To uninstall, choose **Uninstall Druti…** from Druti's input menu.

Requires macOS 14 or later on a Mac with **Apple Silicon** (M1 or later). Druti doesn't run on
Intel Macs.

Want to try it first? The [playground](https://ahamed.github.io/druti-ime/) runs the same engine
in your browser.

## Verify the download

```sh
shasum -a 256 Druti-@VERSION@.dmg
shasum -a 256 Druti-@VERSION@.app.zip
```

Each output should match the matching `.sha256` file attached below.
