**Druti 2.0 changes how two typing rules work, so a few spellings you know will type differently.**
Both rules are ones you can hear, and nothing else changes: the same keys always give the same text,
and `o` still keeps consonants apart everywhere.

- **A single `r` no longer makes reph.** `korte` now gives করতে, `korbo` করব, `dorkar` দরকার, with no
  extra `o`. Type **`rr`** for reph: the second `r` shows the hasant at once (কর্), and the next
  consonant completes it (`korrta` → কর্তা).
- **Nothing joins after a breathy letter** (খ ঘ ছ ঝ ঠ ঢ থ ধ ফ ভ), হ, ড়, ঢ় or য়, except the ফলা keys
  `r l m n N w y`: `dekhte` → দেখতে, `poRte` → পড়তে, `jayga` → জায়গা, while `cihno` → চিহ্ন and
  `dhwoni` → ধ্বনি still join.
- **`y` after a single `r`** is a visible য-ফলা (`poryonto` → পর‍্যন্ত, `ryab` → র‍্যাব). Reph over য is
  typed `rry` or `rrz` (`porryonto` → পর্যন্ত).

| You typed in 1.x | It now gives | Type this instead |
|---|---|---|
| `korta` (কর্তা) | করতা | `korrta` |
| `dhormo` (ধর্ম) | ধরম | `dhorrmo` |
| `ortho` (অর্থ) | অরথ | `orrtho` |
| `poryonto` (পর্যন্ত) | পর‍্যন্ত | `porryonto` |
| `karjo` / `karzo` (কার্য) | কারজ / কারয | `karryo` |
| `korote` (করতে) | করতে | `korte` also works now |
| `dekhote` (দেখতে) | দেখতে | `dekhte` also works now |

`rri` still gives ঋ (`rriN` → ঋণ, `krriShi` → কৃষি).
