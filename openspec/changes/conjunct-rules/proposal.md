> **Status: parked (2026-10-03). Do not apply.** The author chose not to ship a joining list: it
> has to be memorised, which works against typing without looking at the screen. `rr-reph` takes only
> its cheapest, audible rule (nothing joins after a breathy letter), and words such as আমরা, একটা,
> আপনি are left to the optional `autocorrect` change. This folder is kept for its research
> (`research.md`) and in case a joining list is offered later as an opt-in setting.

## Why

Druti joins any two consonants typed in a row, so the typist has to type an `o` they neither say nor
write to keep them apart: `dekhte` gives `দেখ্তে`, `amra` gives `আম্রা`, `ekTa` gives `এক্টা`,
`apni` gives `আপ্নি`. The `rr-reph` change fixes this for র only.

Bengali grammar has no rule that licenses every conjunct, but it has rules for whole families of
them: a nasal before a letter of its own row (ন্ত, ম্প), স/শ/ষ before a stop (স্ত, ষ্ট), a doubled
letter (ক্ক), a plain letter before its breathy partner (দ্ধ), and the ফলা letters. It also has
groups that never join: a breathy letter before another consonant (দেখতে, বুঝতে), য় ড় ঢ় ৎ (জায়গা,
হয়তো), হ except as a ফলা base (তাহলে). And the first vowel of a word is always spoken, so two
consonants typed at the very start of a word can only be a conjunct.

The research for this change (`research.md` in this folder) combined those grammar families with three published conjunct lists, 15 fonts
and two corpora (2.4M-token subtitles, 12.3M-token Wikipedia):

| Rule set | Words right, chat / formal |
|---|---|
| Druti 1.x: join every pair | 47% / 65% |
| `rr-reph` alone | 58% / 71% |
| This change: word-start rule + 107 family pairs | **92.4% / 90.6%** |

Avro and Khipro (a deterministic phonetic layout) already join only listed pairs; all 107 pairs are in
Khipro's table.

## What Changes

- At the start of a word, consonants typed together always join, as today: `glas` → `গ্লাস`, `skul` →
  `স্কুল`, `Tren` → `ট্রেন`. (A single `r` and `z` keep their own rules everywhere.)
- **BREAKING** Inside a word, two consonants join only when the pair is in the joining table (107
  pairs in seven families). Every other pair is written side by side with no hasant: `dekhte` →
  `দেখতে`, `amra` → `আমরা`, `ekTa` → `একটা`, `apni` → `আপনি`, `bolle` → `বললে`, `jayga` → `জায়গা`.
  Listed pairs join as today: `kintu` → `কিন্তু`, `rasta` → `রাস্তা`, `pakka` → `পাক্কা`, `potro` →
  `পত্র`.
- `o` still separates any pair: `janote` → `জানতে`.
- **New** A backtick joins two consonants that the table keeps apart. It shows a hasant at once, and
  the next consonant joins: ``Dok`Tor`` → `ডক্টর`, ``al`lah`` → `আল্লাহ`, ``som`raT`` → `সম্রাট`.
  Two backticks give a visible hasant that never joins: ``ud``din`` → `উদ্‌দীন`. After `r`, a backtick
  is the same as a second `r` (reph).
- **BREAKING** `w` after a consonant is always ব-ফলা (`pokw` → `পক্ব`, `somonwoy` → `সমন্বয়`); `b`
  follows the table. `w` anywhere else is still ব.
- `z` (the letter য) never joins the consonant before it; য-ফলা is typed with `y`, as in `rr-reph`.
- When `h` turns the second letter of a joined pair into a letter the table doesn't join, the hasant
  goes (`akth` → `আকথ`), as `H` already does for ৎ.
- Unchanged: `j` → জ and `z` → য (জ is 1.5–2× more frequent as a standalone letter); `nc` → ঞ্চ,
  `nj` → ঞ্জ, `kkh` → ক্ষ, `gg` → জ্ঞ, `x` → ক্স.
- Exceptions are single pairs in the table, never words. A verb-stem list (থাক, জান, আস) was measured
  to break more correct joins (কিন্তু, চিন্তা, ডাক্তার) than it fixes, so জানতে-type verbs are typed
  `janote`.
- Every decision is made by the key being typed, from the letters since the last vowel and whether
  they start the word. Text before the last vowel never changes.
- Ships with `rr-reph` in Druti 2.0.0, with no setting. Like `rr-reph`, it deliberately overrides the
  project rule that new behaviour defaults to the current one.

### Modified Capabilities
- `rust-engine-core`: new requirements for when consonants join (word start, the joining table, the

## Impact

- **Depends on** `rr-reph`, which must land first: it owns every rule about র as the first letter and
  `y` after র.
- **Rust**: `druti-core` only. `data.rs` gains the joining table; `engine.rs` `process_consonant`
  decides joins from it; `rules.rs` gains the backtick and `w` rules and a hasant check after
  aspiration. Public API and bindings don't change.
- **Fixtures**: every engine fixture where a consonant key follows a consonant mid-word, or that types
  a backtick or `w`, is regenerated by a script that refuses to change any other case. `engine/data.json`
  gains the joining table. New composer cases for the backtick.
- **Hosts**: no Swift or TypeScript changes.
- **Docs**: a new "How consonants join" section in `README.md` with the one-line rule, the family
  table and the full pair list; 2.0.0 release notes extend the `rr-reph` spelling table.
